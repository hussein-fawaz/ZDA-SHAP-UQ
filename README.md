## Overview

Zero-day attacks pose a persistent challenge for network intrusion detection systems, as traditional supervised classifiers struggle to generalize to attack patterns unseen during training. This work proposes a novel detection framework that jointly leverages SHAP-based feature influence reconstruction error, epistemic uncertainty estimation, and Gaussian Mixture Model (GMM) joint modeling to identify anomalous, previously unseen attack behaviors. By combining explainability signals with principled uncertainty quantification, the framework offers both improved detection performance and greater interpretability compared to existing baselines, evaluated across multiple benchmark network intrusion datasets.
